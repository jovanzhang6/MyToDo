# PRD：mytodo-core（磨砂窗口壳 + 三类任务引擎）
> 项目：mytodo · 切片 1/2
> 状态：已评审（2026-09-24 关卡 1 通过）

## 背景与目标

用户（个人，Windows 11）想要一个常驻桌面右上角的淡蓝磨砂玻璃小窗，把「每天要做的事、限时要做的事、想起来就记的事」放进同一份清单；系统自动处理「每天重来 / 到期消失 / 完成归档」，从此不用每天手动重建任务。本切片交付**完整可用的任务清单小窗**（统计与提醒在切片 2）。

## 用户故事（P0 除非标注）

1. 作为用户，我打开电脑就能看到右上角的淡蓝磨砂小窗，随手记录想做的事。
2. 作为用户，我添加任务时不被迫选类型——默认就是不限时；需要时才指定「每日」或「限时 + 到期日」。
3. 作为用户，我点击勾选完成任务，任务划线显示（当天保持可见）。
4. 作为用户，每日任务勾掉后第二天自动恢复未完成，不用重新添加。
5. 作为用户，限时任务到期日次日自动从列表消失，做没做完都不用我管。
6. 作为用户，不限时任务在我删除或完成前一直都在。
7. 作为用户，列表自动按 **限时 > 不限时 > 每日** 排序，我第一眼看到的是最紧急的。
8. 作为用户，我能修改任务类型（不限时 ↔ 限时 ↔ 每日），改完立即按新类型生效。
9. 作为用户，我能编辑任务文字、删除任务。
10. 作为用户，窗口能拖动、缩放、记住位置；点 X 缩到托盘；置顶随时可切换。
11. 作为用户，我可以在设置里开关开机自启。（P0，澄清时明确选择）

## 功能范围

- **P0**：无边框磨砂窗口（右上角默认/置顶切换/拖动/缩放/状态记忆）、托盘常驻（点 X 隐藏、托盘退出）、单实例、开机自启开关、任务增删改、类型三选（默认不限时）、完成勾选划线、三类生命周期自动化（每日重置/限时过期归档/已完成次日清除）、排序、类型转换、跨天补偿、JSON 原子持久化。
- **P1**：透明度调节（默认值由研发视觉定稿）；限时日期快捷项（今天/明天/后天）。

## 非目标（本切片不做，下游据此拒绝蔓延）

1. **统计面板、到期提醒/toast**——切片 2 范围；本切片不出现任何统计 UI 与系统通知。
2. **macOS/Linux 适配**——只对 Win11 验收；代码不得写死平台，但不做适配验收。
3. **子任务/标签/优先级/搜索/批量操作**——任务模型保持「一句话 + 类型 + 到期日」最小形态。
4. **多设备同步/云备份/账号**。
5. **深色主题**——浅色淡蓝是 v1 唯一主题。

## 验收标准（每条可测）

**窗口壳**
- A1 冷启动：窗口出现在主屏右上角（留边距），无边框、淡蓝半透明磨砂质感；失焦后不破相（允许系统回退为 Mica/半透明）。
- A2 按住空白区/标题区可拖动窗口；窗口可缩放且有最小尺寸（约 280×360），不小于该尺寸。
- A3 重启应用：位置、大小、置顶状态与上次一致。
- A4 点 X：窗口隐藏、应用不退出、托盘图标存在；托盘菜单含「显示/隐藏、置顶开关、开机自启开关、退出」。
- A5 置顶切换立即生效，重启后保持。
- A6 重复启动不出现第二个实例（唤起已有窗口）。

**任务引擎**
- B1 添加：输入文字回车 → 成为不限时任务；添加区可切换「每日 / 限时（选日期）」。
- B2 勾选完成：任务划线，当天保持划线可见。
- B3 每日任务跨天（本地 0 点）：已勾 → 重置为未完成仍在列表；未勾 → 保持未完成。
- B4 限时任务：到期日当天仍显示可勾；次日刷新时从列表消失——已勾归档「已完成」，未勾归档「过期未完成」。
- B5 不限时任务：勾选后次日从列表消失（归档「已完成」）；不勾则一直在。
- B6 排序恒为：限时（按到期日升序，今日到期在最前）> 不限时 > 每日。
- B7 类型修改：三类互转立即生效；每日→限时必须补到期日；限时→每日/不限时自动清除到期日；历史归档不受影响。
- B8 编辑文字、删除任务；删除为归档而非物理删除。
- B9 跨天补偿：0 点在线自动刷新；休眠跳过 0 点后，唤醒/首次交互按当前日期补偿，结果与在线跨天一致。
- B10 强杀进程重开：任务与完成状态不丢（原子写入生效）。

## 开放问题（默认假设，可翻案）

- 淡蓝/透明度具体数值：授权研发视觉调优。
- 每日任务当天已勾的显示：保持划线显示至跨天（便于回顾今天做了什么）。
- 限时日期选择交互：今天/明天/后天快捷 + 完整日期选择，研发定稿。
