## 缺陷

| 严重度 | 描述 | 处理 |
|---|---|---|
| 一般 | Acrylic 材质聚焦/失焦透明度不一致（系统级行为），首轮业主反馈 | 已回炉：切 Mica 后又因滑杆失效二次回炉，定为 Acrylic + tint alpha 直控，失焦特性向业主说明并接受（`347ef5e`） |
| 轻微 | CSS 圆角外灰直角（shadow:false 所致） | dev 修复：恢复系统阴影圆角（`1f0eccf`），业主复测通过 |
| 轻微 | 设置面板点击无响应（动态 DOM 模式缺陷） | dev 重写为声明式 DOM + 前端错误黑匣子（`ed4d4ce`），业主复测通过 |
| 轻微 | 引擎不变量：空库首任务跨天时 roll_over 锚点缺失 | 单测暴露，dev 修复（add_task 补锚点不变量），复测通过 |
| 提示 | dev 模式 toast 借用 PowerShell 身份 | 非缺陷：未打包应用无通知身份所致，打包安装后自动纠正（列入切片 2 打包验证项） |
