# PRD：mytodo-miniball（悬浮球模式）
> 项目：mytodo · 新增 M 级切片（与既有功能全兼容）
> 状态：已评审（2026-09-25 关卡 1 通过）

## 背景与目标

窗口常驻右上角挡屏幕是用户的核心痛点（原话「大多数时候这个待办都是挡屏幕的」）。提供**悬浮球模式**：一键把整个窗口收成一颗 ~56px 的可拖动小球，看视频/写文档时球在角落安静显示未完成数，点一下展开回完整清单。成功判据：收球/展球一键来回、球上数字实时准确、展开后一切如旧。

## 用户故事（P0 除非标注）

1. 作为用户，我点标题栏的收球按钮，窗口瞬间收成一颗小球，不再挡屏幕。
2. 作为用户，球上显示未完成任务数，数字随勾选实时变化——瞥一眼就知道还剩多少。
3. 作为用户，球可以被拖到屏幕任何位置，松手停住。
4. 作为用户，单击球展开回完整窗口，位置/大小/状态与收球前一致。
5. 作为用户，全部任务完成时球变绿（或勾号态），给我"做完了"的信号。（P1，视觉增强）
6. 作为用户，球模式下提醒/跨天/统计照常工作——球只是外观，不是另一个应用。

## 功能范围

- **P0**：收球/展球切换（标题栏按钮 + 托盘菜单项）、球体 ~56px 圆形、球面未完成数实时刷新、球可拖动、展开恢复收球前几何、球模式与置顶/透明度/提醒/统计完全兼容、窗口记忆不因球模式污染（展开后的几何才落盘）。
- **P1**：全部完成时球变绿/显示 ✓。
- 非目标：球上右键菜单（托盘已覆盖）；多球；球体皮肤自定义；球模式下的任务操作（点击球即展开，不在球上做任务管理）。

## 验收标准

- F1 点击收球按钮 → 窗口变为 ~56px 圆形球，内容只显示未完成数；无白边、无滚动条、形状为正圆。
- F2 球面数字 = 未完成任务数（含限时/每日/不限时），勾选任务后数字即时 -1（无需重开窗口）。
- F3 球可拖动到任意位置，松手停住不回弹；拖动结束不触发展开。
- F4 单击球（非拖动）→ 展开为收球前的窗口几何（位置+尺寸+置顶状态）。
- F5 球模式下：勾选通知照常、跨天刷新照常、托盘「显示/隐藏」照常作用于球。
- F6 收球前的几何不被球尺寸污染：球模式下强杀进程，重启后窗口是**展开态**（球是临时态，不持久化）。
- F7 与透明度兼容：球的磨砂/透明度跟随当前设置。
- F8 （P1）全部完成时球面变绿或显示 ✓。

## 开放问题（PM 默认假设，可翻案）

- 球默认出现位置 = 原窗口标题栏附近（收球瞬间就地收缩，不跳变）。
- 拖动与点击的区分交给 Tauri 拖动区机制（按住即拖、短按即点），不做自研手势判定。
- 球模式下双击/右键无特殊行为（保持极简）。
