# PRD：mytodo-stats-notify（统计面板 + 到期提醒 + 打包收尾）
> 项目：mytodo · 切片 2/2
> 状态：草稿

## 背景与目标

切片 1 交付了完整可用的三类任务小窗。本切片补齐两块「让数据产生价值」的能力：**统计**（让用户看见自己的坚持与懈怠）与**提醒**（限时任务到期不被遗忘），最后打包成正式安装程序交付（根治 dev 模式 toast 借用 PowerShell 身份的问题）。

## 用户故事

1. 作为用户，我在主界面点一个入口展开统计，一眼看到：今天完成了几件/共几件、三类任务各自的完成率、连续打卡天数。（P0）
2. 作为用户，我看得到近 30 天的完成趋势，哪天没坚持一目了然。（P1）
3. 作为用户，限时任务当天到期时收到一条 Windows 通知，点一下就知道有几件什么事；同一天不被重复轰炸。（P0）
4. 作为用户，「今天到期」的任务在列表里以红色高亮呈现，不用通知也在。（P0）
5. 作为用户，我双击安装一个 exe，得到正式的 MyToDo：自己的通知署名、开机自启真正生效、开始菜单/桌面入口。（P0）

## 功能范围

- **P0 统计**：统计面板（标题栏入口展开/收起，渐进式，不挤占清单）：今日概览（完成/总数）、三类任务各自完成率（今日口径，基于当日任务与勾选状态）、累计归档数。数据全部只读 archive 与任务现状，不改 schema。
- **P0 统计**：连续打卡 streak——以「每日任务」为单位：存在每日任务且当日全部勾选 = 打卡成功日；昨日成功今日未完 = 当前 streak 显示中（含今天）；无每日任务时该指标显示「—」。断签归零，只算连续，不做最长纪录（开放问题留痕）。
- **P0 提醒**：跨天滚动（含 0 点定时器与唤醒补偿）后，若存在「今天到期」的限时任务且今天尚未提醒过 → 发一条 Windows toast（含任务件数，2 件以上列前 3 个任务名）；同任务同天至多一次（记 `last_notified_date` 于数据库）。
- **P0 提醒**：列表内「今天到期」红色高亮已在切片 1 实现，此处作为验收回归项。
- **P0 打包**：`tauri build` 产出 NSIS 安装包；安装后验证：toast 署名 MyToDo、开机自启生效、开始菜单入口、卸载不删用户数据。
- **P1 趋势**：近 30 天逐日完成数/完成率条形图（纯 SVG 手绘，无图表库），数据源为 archive（`removed_date`/完成口径）+ 当前任务，hover 显示当日数字。

## 非目标

1. **自定义提醒时间**（如"前一天 21:00 提醒我"）——澄清时已选择不加，v2 再议。
2. **统计的导出/分享**（图片、CSV）。
3. **周/月粒度聚合视图**——30 天逐日已覆盖，聚合属于锦上添花。
4. **自动更新**（updater）——首版手动安装即可。

## 验收标准

**统计（C 系）**
- C1 标题栏点击统计入口 → 面板展开（滑出或切换），再点收起；收起后不占任何空间。
- C2 今日概览数字正确：完成数 = 当前 done 任务数；总数 = 当日应呈现任务数。
- C3 三类完成率正确：每日任务按「今日应做全部已勾」=100%；限时/不限时按当日列表中该类的 done 占比；无该类任务时显示「—」不显示 0%（0% 与「没有」语义不同）。
- C4 streak：昨日全勾且今日进行中 → 显示连续天数（含今天）；昨日有未勾 → 归零重新计；无每日任务 → 显示「—」。构造历史数据可复现三种形态。
- C5 统计为纯读取：反复开关面板、刷新统计，不产生任何归档记录、不改变任务状态。
- C6（P1）趋势图 30 根柱与 archive 数据一致，hover 显示当日数字。

**提醒（D 系）**
- D1 构造「今日到期」任务，跨天边界触发后收到 1 条 toast，内容含件数。
- D2 同一天内无论刷新/重开窗口多少次，不再重复 toast；次日有新的到期任务才再提醒。
- D3 无到期任务的日子不发任何 toast（零打扰）。
- D4 「今天到期」红色高亮在列表中正确出现与消失（跨天后任务归档即消失）。

**打包（E 系）**
- E1 安装包可双击安装，桌面/开始菜单出现 MyToDo。
- E2 安装版发 toast 署名为「MyToDo」而非 PowerShell。
- E3 托盘勾选「开机自启」后重启系统（或查注册表 Run 键）自启生效；取消勾选即失效。
- E4 卸载后 data.json 保留（重装后任务还在）。

## 开放问题（PM 代做决定留痕，业主可翻案）

- streak 只算「当前连续」不做「最长纪录」：界面少一块，数据想看随时能补。
- toast 文案定稿：「MyToDo · 今天有 N 件任务到期」+ 前 3 个任务名；只发一条聚合通知，不发逐条。
- 统计口径「完成率」按自然日（今天 0 点起算），不做滑动 24h 窗口。
- 趋势图列 P1：若时间紧可顺延到切片 2 之后的小版本，不阻塞验收。
